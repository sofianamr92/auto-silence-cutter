# Auto Silence Cutter

تطبيق مونتاج محلي لاكتشاف الصمت وتحرير المقاطع، مع حفظ محلي ومزامنة اختيارية عبر Supabase.

## تشغيل ميزات السحابة

1. أنشئ مشروعاً في Supabase، ثم افتح **SQL Editor** وشغّل ملف:
   `supabase/migrations/202611190001_initial_cloud_projects.sql`.
   تنشئ الهجرة الجداول وسياسات RLS وbucket خاصاً باسم `project-media`.
2. من **Authentication → Providers → Google** فعّل Google وأدخل بيانات OAuth في لوحة Supabase فقط.
   لا تضع Google Client Secret أو Service Role Key في التطبيق أو Git.
3. أضف عنوان العودة التالي إلى **Authentication → URL Configuration → Redirect URLs**:
   `http://127.0.0.1:8990/auth/callback`
   ويمكن إضافة `http://localhost:8990/auth/callback` أيضاً.
4. في Google Cloud Console، استخدم عنوان callback الذي يعرضه مزود Google في لوحة Supabase
   (عادةً `https://<project-ref>.supabase.co/auth/v1/callback`) كـ **Authorized redirect URI**.
5. انسخ `.env.example` إلى `.env` وضع عنوان مشروع Supabase ومفتاحه العام فقط:

   ```dotenv
   SUPABASE_URL=https://<project-ref>.supabase.co
   SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
   ```

   يقبل التطبيق أيضاً مفتاح `anon` القديم عند الحاجة. لا تضف أي مفتاح سري إلى `.env`.
6. ثبّت المتطلبات وشغّل `python -X utf8 desktop_app.py`. افتح التطبيق على
   `http://127.0.0.1:8990/`.

تُخزَّن جلسة التجديد في Windows Credential Manager، وتُرسل عمليات المشاريع برمز المستخدم
حتى تطبق PostgreSQL وStorage سياسات RLS. إذا لم تُضف إعدادات Supabase، يظل التحرير والحفظ
المحلي متاحين.

## المشاريع والوسائط

- تُحفظ حالة المشروع محلياً في IndexedDB، مع قائمة انتظار للمزامنة وسجل محلي محدود للإصدارات.
- من **My Projects** يمكن البحث عن المشاريع وفتحها أو نسخها أو حذفها، وتصديرها كملف
  `.silenceproject` واستيراده لاحقاً. يتضمن الملف بيانات التحرير والإعدادات والمعاينة، ولا يتضمن
  الفيديو الأصلي؛ عند عدم توفره على الجهاز سيطلب التطبيق إعادة تحديده.
- المشاريع السحابية تحفظ حالة Timeline وتستخدم رقم إصدار لمنع الكتابة فوق نسخة أحدث بصمت.
- تتضمن بطاقة المشروع صورة مصغرة وحجم الوسائط، ويعرض الحساب مساحة التخزين المستخدمة.
- زر **نسخ الفيديو سحابياً** يطلب موافقة صريحة قبل رفع الملف. يستخدم الرفع بروتوكول TUS
  بقطع 6 MiB، ويعرض التقدم ويدعم الإيقاف والاستئناف وإعادة المحاولة أثناء تشغيل التطبيق.
- بعد الرفع، يعاد تنزيل الملف من bucket الخاص وحساب SHA-256 لمقارنته بالملف المحلي.
  عند فتح المشروع على جهاز آخر يمكن تنزيل الوسيط والتحقق منه أو إعادة ربط ملف محلي.
- سعة الملفات وحدود حجمها تعتمد على خطة Supabase وإعدادات Storage للمشروع.

## تصدير الفيديو

- خيار التصدير الافتراضي ينشئ ملف فيديو فعلياً بعد قص المقاطع المحفوظة ودمجها بواسطة FFmpeg.
- يمكن أيضاً إنشاء حزمة CapCut تحتوي الفيديو النهائي، المقاطع المنفردة، وبيانات القص بصيغ JSON وCSV.
- خيار EDL / JSON يحفظ نقاط القص إلى جانب الفيديو في مجلد التصدير.
- يستخدم التصدير قصاً دقيقاً مع إعادة ترميز H.264 بجودة عالية؛ القص الدقيق عند حدود إطارات غير رئيسية لا يمكن ضمانه باستخدام stream copy وحده.

## اختبار الميزات المحلية

```powershell
python -m pytest tests\test_cloud_auth.py tests\test_cloud_projects.py tests\test_cloud_media.py -q
```

اختبارات OAuth ورفع الملفات الحقيقية تتطلب إعداد Supabase فعلياً وتطبيق ملف SQL؛ لا تشغّل
اختبارات القبول التي تتطلب حساب Google أو مشروعاً سحابياً قبل إضافة هذه الإعدادات.
